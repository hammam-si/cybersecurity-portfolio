# Cybersecurity & Red Team Portfolio
Selamat datang di repositori portofolio keamanan siber saya. Repositori ini mendokumentasikan perjalanan saya dalam mempelajari *Offensive Security*, mulai dari setup lab lokal, eksploitasi web application (SQLi, XSS), hingga pelaporan kerentanan (Vulnerability Disclosure) pada sistem nyata secara etis.

## Struktur Repositori
- `01-reconnaissance-and-disclosure/`: Laporan audit keamanan dan *Ethical Disclosure* pada sistem institusi (VClass & MyUnila).
- `02-web-app-exploitation/`: Dokumentasi praktik *Red Teaming* pada lab lokal (DVWA), mencakup SQL Injection dan Cross-Site Scripting (XSS).
- `03-tooling-and-environment/`: Dokumentasi setup infrastruktur lab menggunakan Docker.

## Disclaimer
Semua aktivitas yang didokumentasikan di sini dilakukan untuk tujuan edukasi dan pengujian keamanan yang sah (Ethical Hacking).
